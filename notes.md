##CONSTRUCTOR

1. It is used to initialize a properties of an object.
2. Since it is initializing propertyt of an object it is also called as Initializer/special method/--init-- method.
3. Constructor will be declared inside a class with the help of **init** method.
4. By default it will accept one Arguement as mandatory that is self.
5. self is a reference variable which is used to hold the address of an object.
6. Apart from self we can pass any other name by as per industrial standard we have to pass self.
7. We can able to pass multiple constructor in same class but previous one will get override by the new one.
