1. What is OOPs in Python?
   OOPs stands for Object-Oriented Programming System.

   It is a programming approach in which we write programs using classes and objects.

2. what is a class?
   A class is a blueprint or template used to create objects. It defines the attributes and methods that its objects can have.

3. What is the object?
   An object is an instance of a class. It can have data in the form of attributes and behaviour in the form of methods.

4. What are the attributes?
   Attributes are the variables that store the data or properties of an object. They describe the characteristics of an object.

5. What is the behaviour?
   Behaviours are the actions that an object can perform. In Python, behaviours are defined using methods inside a class. For example, a mobile phone can make calls and take photos, which are its behaviours.
